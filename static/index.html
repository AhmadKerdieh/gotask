A minimal task tracker, now behind real auth.

Every /api/v1/projects and /api/v1/tasks call now requires a verified Keycloak token. Login uses the Authorization Code flow with PKCE — no client secret, the correct pattern for a browser SPA. The task you create is attributed to you, the authenticated subject, not a stub.

session checking…

The access token lives in memory only (not localStorage — a token in localStorage is readable by any injected script). It is sent as Authorization: Bearer on every API call. When it expires, the next call returns 401 and you're bounced back to login.
